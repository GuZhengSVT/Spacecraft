## 重建与对照结果

本次直接查看国博结构星照片：
https://www.chnmuseum.cn/zp/jzrgs/202203/W020220304482204517519.jpg

| 对照项目 | 实现 |
| --- | --- |
| 近球形 72 面体 | 12 个经向分区、6 个纬向面带，共 72 块独立蒙皮；名义半径 0.5 m |
| 上下半球壳与环形腰带 | 分面壳体、带状中部结构与上下凸缘 |
| 银灰色金属外观 | 铝合金材质、深浅分面；对照照片降低过亮反光 |
| 接缝与铆接 | 分面边缘窄缝、成排紧固件 |
| 腰带矩形窗口 | 深色内凹窗口与金属边框，对齐十二边腰带平面 |
| 四根短波天线 | 每根四节，每节 0.75 m，总长 3 m；附底座、绝缘环及套接节 |
| 顶部超短波天线 | 长 0.4 m，带安装底座 |
| 底部连接结构 | 倒锥形连接部与圆形边缘；未复刻博物馆展示支架 |

模型为本项目重建，不是官方提供的三维资产。整体尺寸、天线数量与长度来自国博结构星说明；分面分区、窗口数与间距、铆钉排布、安装座、天线截面、材质参数依据照片作展示性重建。当前建模对象采用国博结构星外观与展开天线状态；不宣称精确还原入轨飞行器每一个表面细节。
